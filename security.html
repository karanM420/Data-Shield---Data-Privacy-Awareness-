Data security is about protecting information from unauthorized access, loss or misuse. Strong security practices can reduce the chances of personal information being compromised online.

01 // DATA SECURITY

HOW IS DATA PROTECTED?

Security measures such as encryption, authentication and access controls help protect information stored on devices, websites and online services.

Both technology and user habits are important for keeping data secure. A secure system can still be put at risk by weak passwords or careless sharing.

COMMON SECURITY MEASURES

  • Encryption
  • Strong authentication
  • Access controls
  • Regular security updates
02 // SECURITY HABITS

SECURE YOUR ACCOUNTS

Good security habits can make your online accounts harder to access without permission.

Using unique passwords, enabling two-factor authentication and keeping your devices updated are simple steps that improve account security.

GOOD PRACTICES

  • Use strong and unique passwords
  • Enable two-factor authentication
  • Keep software updated
  • Protect your login information
